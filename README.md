TimeLeft

A simple and interactive countdown timer built with React.

This project is a small practice project focused on working with React's State, useEffect, events, and basic JavaScript logic.

Preview

![TimeLeft Preview](./Capture.PNG)

Features

-Countdown timer

-Automatic time update every second

-Built with React useState and useEffect

-Styled with CSS Modules

-Disables the discount button when the timer expires

-Displays an expiration message when the countdown reaches zero

-Button animation while the timer is active

Technologies

-React

-JavaScript

-CSS Modules

-React Hooks

->useState

->useEffect

What I Learned

-While building this project, I learned and practiced:

-How to use useState to manage the countdown state

-How to use useEffect to handle side effects such as setInterval

-How to clean up an interval using clearInterval

-How to work with JavaScript functions and basic time calculations

-How to use CSS Modules for component-specific styling
